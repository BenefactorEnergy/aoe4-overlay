### 🎮 Core Overlays
- Real-Time Stats — view unit counts, resources, and population on screen
- Unit Tracker — track enemy and ally unit positions in real-time
- Resource Monitor — monitor income and spending rates
- Minimap Radar — enhanced minimap with unit detection

### 🎨 UI & Customization
- Custom HUD — fully customizable overlay layout
- Hotkey Manager — assign hotkeys for quick actions
- Build Helper — recommended build orders on screen
